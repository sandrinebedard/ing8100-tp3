## How to contribute to this project

Please follow these simple guidelines to keep contributions organized and easy to review.

- **Use issues** to report bugs, request features, or ask questions. When opening an issue, choose the appropriate label ("bug", "feature", "question") and include a short description, steps to reproduce (for bugs), and suggested behavior or motivation (for features).
- **Open a Pull Request (PR)** to propose code changes. Base your PR on a feature branch, include a clear title and description, reference any related issue (e.g., "Fixes #12"), and keep changes focused and well-documented.
- **Discuss before large changes**: for major refactors or architecture changes, open an issue first to gather feedback before implementing.
- **Keep commits small and focused** and follow the repository's formatting and style conventions where possible.

Thanks for contributing — your improvements help keep the project reproducible and robust.
